# バックエンド資産活用マップ

> **目的**: `backend/` 配下の豊富な資産をNiceGUI UIでフルに活用するためのマップ
> **現状**: 現在のNiceGUI UIでは殆ど採用されていない資産が多い

### 4.2 EDA（指示2：EDAは解析前の必経ステップ）

| ファイル | 機能 | UIでの活用法 |
|---|---|---|
| `eda_chem.py` | 化学特化EDA | 基本統計・可視化、SMILESホバー |
| `auto_analyzer.py` | 自動解析（疑似OFAT等） | 異常値・重複検出 |
| **【追加活用】** | **インタラクティブ・フィルタリング** | 変数範囲・カテゴリで絞込み、即時反映 |
| **【追加活用】** | **データ熟読支援** | 特定サンプルの全特徴量詳細表示、変数ごとの記憶支援 |
| **【追加活用】** | **フィルタ前後比較** | 全データvs絞込みデータの分布比較 |

**EDAの位置づけ**: MLモデリングの前に配置。ユーザーが「サンプル名を言われたらその説明変数の値がぱっと浮かぶ」レベルまでデータを熟読してからモデリングへ進めるよう、backend/eda/の全機能をNiceGUIで活用。

## 9. NiceGUI UIでの統合優先順位

### 最優先（即時統合）
1. `backend/chem/*_adapter.py` - 化学計算エンジン
2. `backend/ml/estimators.py` + `constrained_boosting.py` - MLモデル
3. `backend/llm/interview_session.py` - LLMヒアリング
4. `backend/constraints/` - 単調性制約
5. `backend/doe/` - 実験計画法

### 高優先（早期統合）
6. `backend/optim/` + `backend/inverse/` - 逆解析
7. `backend/interpret/` - SHAP, PDP等
8. `backend/eda/` - EDA機能
9. `backend/ml/pipeline_orchestrator.py` - パイプライン

### 中優先（順次統合）
10. `backend/export/` - エクスポート
11. `backend/data/` - データ管理
12. `backend/preprocessing/` - 前処理

### 低優先（将来統合）
13. `backend/legacy/` - レガシー（参考用）
14. `backend/hsp/` - 特殊用途
15. `backend/mlops/` - 本格運用時

---

**このマップに基づき、backend/の資産を順次NiceGUI UIに統合していくことで、ユーザーの「全資産を活用したい」要望を満たす。**
