## 1. ユーザー評価サマリー

### 1.1 評価概要
- **評価者**: 有機材料研究者（機械学習は初心者、化学・ポリマーは専門）
- **評価対象**: ChemAI2 アプリケーション（仕様書に基づく）
- **総合評価**: 85/100点（コンセプトは優れているが、初心者向けガイダンスが必要）

### 1.2 主な評価ポイント
1. **良い点**
   - LLM支援が心強い（次に何をすべきかを教えてくれる）
   - EDA重視のフロー（データを熟読してからMLに進む）
   - ドメイン知識の入力機能が画期的
   - 意思決定支援というコンセプトが明確
   - 自動テスト結果の即時表示（アップロード直後）

2. **改善点**
   - UIの複雑さ（初心者にはどこから手を付けて良いか迷う）
   - パラメータ調整の敷居（LLMがもっと能動的に提案してほしい）
   - SMILESの扱い（構造式の可視化と簡易編集機能が欲しい）
   - 計算時間の見積もり（重い計算前に目安を表示してほしい）
   - 初心者モードの不在（LLMが全ステップを自動で進めてくれるモードが欲しい）
   - 用語の専門的すぎ（「特徴量」「モデル」「学習」を平易化してほしい）
   - エラー時のLLMサポート不足（テスト失敗時に原因と修正案を提示してほしい）

### 1.3 ドメイン知識管理に関する要望（重要）
ユーザーは以下のような**くだけたドメイン知識**を簡単に保存したい：
- **変数の性質**: 「温度が上がると屈折率は下がる」
- **制約**: 「フッ素導入は避けたい」「相溶性に注意」
- **系全体に関する知識**: 「比率0.6超で相分離が始まる」

これらを「メモ」や「注釈」として、各ページで簡単に入力・保存できる機能が必要。

## 2. 改善方針

### 2.1 用語の平易化（最優先）

| 現在の用語 | 改善後の用語 | 理由 |
|---|---|---|
| **特徴量** | 説明する変数 / データの特ちょう | ユーザーが理解しやすい |
| **予測** | 推定 / 推測 | 「未来を予測」ではなく「値を出す」ニュアンス |
| **モデル** | 予測式 / 計算式 | ML用語を避ける |
| **学習** | 作る / 作成 | 「学習」は誤解を招く |
| **交差検証（CV）** | 精度チェック | ユーザーには意味が伝わらない |
| **特徴量選択** | 変数を選ぶ | シンプルに |
| **EDA** | データを眺める | 専門用語を避ける |
| **意思決定支援** | 次のアクション提案 | 目的が明確 |

### 2.2 ガイダンスの強化

#### 2.2.1 ステップバイステップ誘導
```
【現在のステップ 2/5】
┌─────────────────────────────────────┐
│ ❶ データを入れる → 完了 ✅          │
│ ❷ 目標を決める → 実施中...        │
│ ❸ データを眺める → 未              │
│ ❹ 条件を提案させる → 未            │
│ ❺ 結果を確認する → 未              │
└─────────────────────────────────────┘

【今やるべきこと】
「屈折率を1.6以上にする」ために、まずはデータを確認しましょう。
```

#### 2.2.2 AI相談のガイダンス
- 会話開始時の初期メッセージを充実
- 「例：屈折率を1.6以上にしたい」等の例文を表示
- ステップごとの誘導メッセージ

#### 2.2.3 用語のホバー説明
- 専門用語にマウスオーバーで説明を表示
- 「？」アイコンクリックで詳細説明をポップアップ

### 2.3 目標の常時表示

```
┌─────────────────────────────────────┐
│ 目標：屈折率を1.6以上にする         │
│ 現在の達成確率：28%（もっとデータが必要）│
└─────────────────────────────────────┘
```
